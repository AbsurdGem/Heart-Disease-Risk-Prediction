# Heart Disease Risk Prediction Using Machine Learning and Neural Networks

## Project Overview

This project applies machine learning and deep learning techniques to predict the likelihood of heart disease using the UCI Heart Disease dataset. The project follows the complete data science workflow, including data cleaning, exploratory data analysis (EDA), feature engineering, predictive modeling, neural network implementation, scenario analysis, and interactive dashboard development.

The goal of this project was to answer three research questions:

1. Which patient characteristics are the strongest predictors of heart disease?
2. Which predictive model performs best?
3. How do changes in important clinical features affect predicted heart disease risk?

---

## Dataset

**Dataset:** UCI Heart Disease Dataset

The dataset contains patient demographic information and clinical measurements commonly used to evaluate cardiovascular disease risk, including:

- Age
- Sex
- Resting Blood Pressure
- Cholesterol
- Chest Pain Type
- Exercise-Induced Angina
- Resting ECG Results
- Maximum Heart Rate
- ST Depression (Oldpeak)
- Heart Disease Diagnosis

---

## Project Workflow

The project was completed in multiple phases:

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Preprocessing
- Logistic Regression Baseline Model
- Neural Network Development using TensorFlow/Keras
- Model Evaluation
- Feature Importance Analysis
- Scenario Analysis
- Interactive Power BI Dashboard

---

## Results

Both the Logistic Regression and Neural Network models successfully predicted heart disease risk. The Neural Network achieved slightly better overall performance across Accuracy, Precision, Recall, and F1-Score.

Scenario analysis demonstrated how changes in patient characteristics influenced the model's predicted probability of heart disease. Interactive Power BI visualizations allow users to compare model performance and explore hypothetical patient scenarios.
